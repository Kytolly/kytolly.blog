IRASim：面向机器人操作的细粒度世界模型
2026 八月 9日
World Model
Robotic Learning
Video Generation
Model Predictive Control

一句话结论

IRASim 将动作轨迹作为逐帧条件注入扩散视频模型，在离线机器人数据上获得了较好的动作—画面对齐，并可用于策略排序与规划；但它仍是一个推理缓慢、依赖任务内 rollout 数据、且物理正确性主要由视觉重建与下游结果间接验证的生成式世界模型。

论文信息卡片

标题：IRASim: A Fine-Grained World Model for Robot Manipulation 作者：Fangqi Zhu, Hongtao Wu, Song Guo, Yuxiao Liu, Chilam Cheang, Tao Kong 状态：2025， arXiv:2406.14540v2 资源：项目

研究问题与定位

论文研究的是 trajectory-to-video：给定历史视觉观测与未来机器人动作轨迹，生成机器人执行这些动作后可能出现的视频。形式化为

其中 是历史帧数量， 是动作数；机械臂动作通常为 7 维，包括三维平移、三维旋转和夹爪状态。

作者认为，通用视频生成模型虽然能生成视觉上合理的视频，但不足以作为机器人世界模型，因为机器人应用需要：

  1. 细粒度动作服从性：每个时刻的动作都应对应到正确的视频帧，而不是只让整段视频符合一个粗略条件；
  2. 接触与失败建模：应能呈现抓取、滑落、推动等机器人—物体交互；
  3. 可用于决策：生成结果应能区分策略优劣、排序候选轨迹，并改善控制结果。

IRASim 的定位不是学习显式状态转移或接触动力学，而是直接在像素潜空间中学习一个动作条件的视频生成器。它更接近“可由动作查询的视觉预测模型”，而不是能够实时闭环交互的完整模拟器。

核心贡献

论文的主要贡献可以归纳为三点：

  • 提出基于扩散 Transformer 的机器人轨迹到视频模型，并比较整段轨迹条件化的 Video-Ada 与逐帧条件化的 Frame-Ada；
  • 在 RT-1、Bridge、Language-Table 和 RoboNet 上验证短、长轨迹视频预测，并展示模型规模和训练步数增加时的性能变化；
  • 将模型用于 LIBERO 策略评估、Push-T 与真实机器人轨迹排序，以及键盘/VR 控制等下游场景。

其中真正具有方法辨识度的部分是 Frame-Ada：它显式建立第 个动作与第 个预测帧之间的条件连接，降低整段动作被压缩成单一向量后产生的时间错配。

方法

总体架构

IRASim 的潜空间扩散 Transformer，以及 Video-Ada 与 Frame-Ada 的条件注入差异。

处理流程如下：

  1. 使用冻结的 SDXL VAE 将历史帧和待预测帧压缩到潜空间；
  2. 只对未来帧潜变量加噪，历史帧保持无噪并作为上下文；
  3. 将潜变量 patchify 后输入交替的空间注意力与时间注意力模块；
  4. 将扩散时间步和动作轨迹编码为自适应归一化参数；
  5. 预测未来帧上的噪声，去噪后经 VAE 解码为视频。

空间与时间注意力被因子化：空间模块在每帧内部建模物体与机械臂结构，时间模块在同一空间位置上建模跨帧变化。这比对所有时空 token 做全注意力更节省计算，也保留了视频建模所需的时序联系。

Video-Ada 与 Frame-Ada

Video-Ada 先把整条动作轨迹编码为一个视频级条件，再用同一组自适应归一化参数调制各帧。优点是结构简单，但动作时序可能在全局压缩中被弱化。

Frame-Ada 在空间注意力块中，让每个动作 独立产生对应帧的 AdaLN 缩放与偏移参数；时间注意力块仍使用视频级轨迹条件。它同时保留：

  • 帧级动作对齐，用于控制当前帧的局部变化；
  • 整体轨迹语义，用于保持跨帧运动连续性。

从实验结果看，Frame-Ada 在作者优先采用的 PSNR 和 Latent L2 上普遍优于 Video-Ada，支持“细粒度动作条件比整段条件更有效”这一核心主张。

长视频通过自回归方式生成：把上一段预测结果重新作为历史上下文，再生成下一段。评测序列平均长度约为 RT-1 42.5 帧、Bridge 33.4 帧、Language-Table 23.7 帧；定性示例可延伸到 150 帧以上，但这不等价于长时域误差已经被严格控制。

指标选择

作者将轨迹到视频视为受精确动作约束的重建问题，因此把 Latent L2 和 PSNR 作为主要指标，SSIM、FID、FVD 作为辅助指标。这个选择有一定合理性：FID/FVD 衡量分布或视觉质量，但不直接验证动作是否被正确执行。

同时也要注意，PSNR 与潜空间误差仍主要衡量像素/表征接近度，不能单独证明抓取力、摩擦、接触或因果动力学正确。论文对“细粒度物理”的证据仍以视觉一致性为主。

视频生成结果

定性结果

RT-1、Bridge 和 Language-Table 上的短轨迹与自回归长轨迹预测。

示例表明模型能够维持背景、机械臂和目标物体的整体一致性，并生成推动、抓取等细节。长序列中仍需警惕两个问题：

  • 每段生成都依赖之前的预测，误差会自回归累积；
  • 视觉上连续并不自动意味着动作幅度、接触事件和物体位姿在数值上准确。

长轨迹结果

Frame-Ada 在长轨迹上的 Latent L2 / PSNR 分别为：

  • RT-1：0.2408 / 24.615；
  • Bridge：0.2306 / 23.260；
  • Language-Table：0.1730 / 26.773。

与短轨迹相比，RT-1 和 Bridge 的误差上升，符合自回归漂移预期。Language-Table 的下降较小，可能与任务运动和背景更简单有关。

人类偏好评测

论文让 5 名参与者各评价 90 对视频，Frame-Ada 相对基线获得更高偏好。它提供了对自动指标的补充，但样本人数较少，而且偏好判断主要反映视觉可信度，不等于验证动作因果性或真实物理参数。

用作策略评估器

模型既生成成功放置，也呈现碗从夹爪滑落等失败过程。

作者在 LIBERO 的一个任务上训练扩散策略，并选取 4 个不同训练阶段的 checkpoint。每个策略分别在 MuJoCo 和 IRASim 中评测 50 次；IRASim 中的成功与否由人工判断。

策略 checkpoint MuJoCo 成功率 IRASim 成功率
1 0.18 0.28
2 0.50 0.48
3 0.80 0.74
4 1.00 0.96

两者 Pearson 相关系数为 0.99，说明 IRASim 对这些 checkpoint 的相对排序非常一致。不过需要限制结论边界：

  • 只有一个任务和 4 个数据点，高相关系数可能不稳定；
  • IRASim 使用包含成功与失败的该策略 rollout 进行后训练，并非广泛策略上的零样本评估；
  • 成功标签依赖人工观察，且绝对成功率仍有偏差；
  • 结果更能证明“在匹配分布上可作代理排序器”，尚不能证明可替代物理模拟器。

模型规划与测试时扩展

规划流程是：从基础策略采样 条动作轨迹，分别用 IRASim 生成结果，给预测的最终帧打分，再执行价值最高的候选。其本质不是梯度规划，而是 采样—想象—排序。

真实机器人轨迹排序

真实机器人实验包含关抽屉、把橘子放到绿盘、把橘子放到红盘三个任务。每次采样 50 条轨迹，以目标图像作为终点参考，执行得分最好的 5 条候选；每个任务重复三轮。

排序方式 关抽屉 绿盘放置 红盘放置
随机 0.20 0.07 0.13

简单像素 MSE 反而优于 ResNet50 特征距离，说明在固定视角、目标图像明确的场景里，通用语义特征未必是最合适的控制代价。另一方面，这些任务存在于训练数据中，实验主要验证任务内规划，而不是对未见任务的泛化。

灵活控制演示

论文展示了在 Language-Table 上使用键盘、在 RT-1 上使用 VR 控制器输入动作。输入可能偏离离线数据分布，生成结果仍大体保持视觉稳定。

附录中，一个要求机械臂向下穿过桌面的物理不可能动作没有被严格执行，模型让机械臂继续停留在桌面上。这个例子具有双重含义：

  • 积极解释：数据先验帮助模型拒绝明显不合理的视觉结果；
  • 消极解释：模型可能用“看起来合理”覆盖动作条件，削弱严格的动作服从性。

对机器人世界模型而言，物理先验与控制忠实度之间的这种张力需要单独评测，不能只看生成视频是否自然。

规模、训练成本与推理速度

作者训练了四种模型规模：S 33M、B 132M、L 461M、XL 679M。随着参数量和训练步数增加，各数据集的 Latent L2 总体下降，表明该任务具有一定可扩展性。

主要训练设置为 AdamW、学习率 、batch size 64、梯度裁剪 0.1、EMA 0.9999；推理使用 50 步 PNDM。论文正文与规模曲线使用 300k 训练步，但附录超参数表列出 3,000,000 步，两处存在 10 倍不一致，复现时应优先向作者核实，而不应静默选取其中之一。

报告的训练开销约为：

  • RT-1：32 张 A800-40GB，2381 GPU 小时；
  • Bridge：32 张 A800-40GB，2371 GPU 小时；
  • Language-Table：32 张 A100-80GB，2369 GPU 小时。

推理 16 帧在 A100 上约需 30 秒、占用约 8 GB 显存。这个速度远低于实时闭环控制需求，也是作者明确承认的主要限制；论文建议后续采用扩散蒸馏。

解读：IRASim 的价值在于把机器人动作条件视频生成从“整段轨迹提示”推进到“逐帧动作调制”，并用策略评估和轨迹排序证明视频世界模型不只可用于可视化。Push-T 中 、大 反而恶化的结果尤其重要，它诚实地揭示了世界模型规划对失败数据与分布覆盖的依赖。因此，这篇论文最稳妥的结论不是“视频模型已经成为机器人模拟器”，而是：在任务和策略分布得到充分覆盖、且价值函数合适时，细粒度动作条件视频模型可以成为有效的离线预测与候选排序器；一旦脱离覆盖范围，视觉生成误差会直接转化为控制风险。

关键假设与局限

  1. 离线覆盖假设：训练数据需要覆盖规划策略可能访问的状态与失败模式；否则模型误差会被搜索放大。
  2. 视觉可判定假设：实验默认任务成功和轨迹价值能从生成图像判断，对隐含力、关节负载或遮挡状态不一定成立。
  3. 短历史假设：多数实验只使用一帧历史观测。作者在 Bridge 上发现两帧帮助有限，并推测相对动作包含速度信息，但单帧通常无法完全消除速度、接触状态等部分可观测性。
  4. 动作—帧对齐假设：Frame-Ada 假设动作频率与视频帧一一对应。真实系统的控制延迟、非均匀采样和动作持续时间可能破坏该关系。
  5. 生成合理性不等于因果正确性：模型可能拒绝不符合数据先验的动作，产生自然但不忠实的结果。
  6. 效率限制：扩散采样约 30 秒生成 16 帧，当前更适合离线评估与慢速规划，而不是实时 MPC。
  7. 评测范围有限：策略评估只有一个 LIBERO 任务；真实规划任务也位于训练分布内。
  8. 计算成本高：单数据集训练约 2300 多 GPU 小时，不利于快速迁移和小规模复现。

复现提示

  1. 先在单一、固定视角数据集上复现 Frame-Ada 与 Video-Ada；
  2. 同时报告 PSNR、Latent L2 和动作执行误差，例如末端执行器/物体位姿误差；
  3. 分别使用专家数据、成功 rollout、失败 rollout 训练世界模型；
  4. 固定候选生成器，扫描 与 ，重点检查扩大搜索是否出现模型利用；
  5. 用独立真实环境评估被选轨迹，而不是只评估生成视频；
  6. 核实 300k 与 3M 训练步的不一致，并记录实际总样本更新量。

开放问题

  • Frame-Ada 的收益来自更好的时间对齐，还是仅来自增加条件参数容量？可用随机打乱动作—帧映射或参数量匹配消融检验。
  • 世界模型对动作幅度、延迟和接触事件是否校准？可以构造局部反事实动作对，测量预测位姿变化的单调性与灵敏度。
  • 能否显式估计不确定性，并在规划时惩罚分布外候选，减少 时的模型利用？
  • 使用状态/几何/力觉辅助监督，是否能把“视觉上合理”推进到“动力学上可验证”？
  • 蒸馏或一致性模型能否把 30 秒降到闭环控制所需的亚秒级，同时保持动作服从性？
  • 能否跨机器人形态、相机视角和控制频率迁移，而不是为每个数据集重新训练大型模型？
